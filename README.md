# IBM-Z-Datathon-26

Lamb Curry's Repository for IBM Z Datathon 2026.

## Description of Project: 
This project has been carefully considered since it would benefit us in our daily lives and because some people struggle with these issues and are unable to get the necessary assistance. 

By using an AI-driven score that scales fitness and nutrition activities and provides recommendations based on real-time moods and energy levels, we aim to deviate from the traditional health app architecture, which focuses on high intensity routines and strict meal plans that cause anxiety, guilt, or distress for vulnerable users.

## Problem Statement:
Since, we are all CS university students we have agreed on that it is difficult to remember when to eat and how beneficial the calories we consume are. So we decided to create this project to encourage everyone with similar issues whether it being mental health, sedentary life-style, or other issues related to the matter. This should help people hit their caloric intake, and avoid situation where they're in a dangerous calorie deficit. 

## Data Set:
We have gathered a dataset from a fitness tracker app that contains data that was recorded daily, such as steps taken, total distance covered, various activity levels and there lengths, estimated calories burnt, and sedentary minutes. There was a total of 7.5B data points, however for our project we only utilised 14,000 data points in our training of AI model.

## Solution: 
Applied secure AI data handling and analysis to identify risky situation, which enabled us to compare the average caloric intake and activity level based on the conditions of their day-to-day life. The accuracy of the model is determined on the time-frame of the project due it's time constraints we couldn't of used the full data set, and if we were to have a longer period it would've been more accurate. 

## Leveraging IBM-Z Resources:
We have used the Linux One server to host our web-application, Isolation Forest to train our AI model with our dataset, and we are running our AI model using the IBM mainframe.
